## 보존한 상태

- 구현 PR 6개와 Codex 0.162.1 대화 파싱 수정은 병합됐다. 최종 구현 후보의 macOS tests·fmt·clippy, Linux·Windows release 빌드와 제품 문서 검사가 통과했다.
- 수정 후보의 실제 첫 회차는 미완료로 중단됐으며 필수 32조건·13영역의 전체 통과를 확보하지 못했다. 남은 두 회차는 실행하지 않았다. 이전 후보의 실패·미완료 원본도 보존한다.
- 실제 Codex 재개·종료와 출력 보존, 코드 44바이트의 공유 복사 복원, 변경된 목록 표시의 원문 복원 불가 시 선택 유지는 부분 관찰이다. 전체 인수조건 통과를 뜻하지 않는다.
- 격리 자동 업데이트는 파일 교체 이후 설치 완료·자동 재실행·원래 shell PID 보존을 확인하지 못했다. 수동 후보 실행을 업데이트 성공으로 처리하지 않는다.
- 검수 중 합성 코드가 실제 CLI 사용자 메시지로 기록되고 닫힌 로컬 모델 주소에 연결을 시도했다. 게시 기록에 Return이 없으며 원인은 미확인이다. 해당 전용 CLI와 검수 GUI를 종료했다. 원본 클립보드는 RAM 보호·복원했고 기록에 저장하지 않았다.

## 이번 공개 범위

추가 실제 검수, 세 번의 전체 검수 통과, 별도 빌드 전·공개 전 전체 native E2E, 최종 서명 ZIP의 GUI 실행·업데이트·IPC·shell PID 검수를 생략한다. 공개 증거는 `schema: 2`, `native_result: blocked`와 미완료 항목 7개를 유지한다. 완료하지 않은 검수를 `passed`로 바꾸지 않는다.

release-plz가 생성한 버전·태그를 사용하며 기존 Developer ID·활성 Sparkle 키를 재사용한다. universal 아키텍처, Developer ID 서명, Apple 공증·stapled ticket·Gatekeeper, ZIP 해시·appcast·업데이트 서명, 동일 draft assets 공개와 Homebrew 갱신은 기존 절차로 수행한다. 공개 후 확인도 파일·서명·업데이트 피드·Homebrew·Pages의 읽기로 한정하고 실제 GUI 검수는 재개하지 않는다.

검증기는 main에 커밋된 정확한 승인 bytes와 후보 SHA·tree·설정, 별도 단계 readback, 60분 freshness, 정확한 immutable draft ZIP을 요구한다. 다른 후보나 다음 버전에는 적용하지 않는다. 이번 릴리스는 전체 native 검수 완료 릴리스가 아니다.
