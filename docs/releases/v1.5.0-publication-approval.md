## Actual validation

All 26 checks passed on release PR #292, including macOS and Linux workspace
regression, Windows build and Linux package and desktop checks. See the
[PR CI run](https://github.com/magicsih/chda/actions/runs/39900108383) and
[package run](https://github.com/magicsih/chda/actions/runs/39900108378).
An earlier main run timed out twice in the Dracula theme preview scenario.
The fresh release-PR run passed, and that preview responded in the native
development observation. CI is separate from native acceptance.

The first independent native attempt captured forty formal screenshots using
declared test-fixture CLIs, not authenticated provider sessions. It observed
Sessions shortcuts for rows 1 through 10, a missing tenth row, font reset,
hidden and collapsed Sessions, split Claude and Codex rows, another repository
and a Git view. It also partially exercised theme, quota, permission, close
confirmation and notification behavior. The fifty conditions were classified
as 22 partial, 26 not run and two blocked, with no complete condition pass.
Eleven feature areas were partial; App updates and Diff review were not run.
Two earlier fixture-preflight screenshots were excluded from that evidence.

After a notification popup, the native-control tool could no longer attach to
the QA window. CoreGraphics still reported the private window onscreen.
Exact-path and bundle-ID connections failed after private GUI relaunch and
with two other independent agents and fresh profiles. Errors included
`cgWindowNotFound`, `noWindowsAvailable` and `timeoutReached`. The second and
third attempts received no native window state or input; all fifty conditions
and thirteen feature areas remain not run in each. No product defect was
established by this tool failure. Last-window close and Dock reopening,
detached-row reconnect, rendered service reconnection and recovery remain
incomplete. Physical reboot and power-loss testing were not performed.

Separate private IPC snapshots around an exact-GUI SIGKILL and isolated relaunch
showed the same service PID and all twelve original running session PIDs.
This process check does not establish screen, image or input reconnection,
Dock reopening, full recovery or any signed-artifact runtime result.

Normal complete native review rounds: **0**. Both complete native E2Es and all
eight exact signed-ZIP GUI and service checks remain unrun. Public evidence
retains `schema: 2`, `native_result: blocked`, and all eleven incomplete checks:
