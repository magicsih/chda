추가 설계 1.1 · 검토 대기 · 구현 시안

chda가 추가한 title / notify -c 설정이 Codex 0.161.0의 공유 서버 선택 조건에 걸립니다. 일반 실행에서 이 주입을 제거하고 provider의 정확한 대화 상태를 별도 연결로 받는 방안을 검토합니다.

제안 구조

실선: 원래 provider 통신 · 점선: 확인된 상태만 보고 · 실제 중계 실행은 미검증

활성화 조건

--remote는 Codex의 client 설정 처리도 바꿉니다. 기본 실행과 대조해 권한·sandbox·관리되는 인증·user notify·resume·동시 pane이 같은 계약을 만족할 때만 적용합니다. 공유 서버 연결 성공만으로 통과하지 않습니다.

조건을 만족하지 못하면 #173을 차단 상태로 두고 근거와 대안을 다시 검토합니다. 전역 설정 수정이나 자동 embedded 전환은 포함하지 않습니다.
