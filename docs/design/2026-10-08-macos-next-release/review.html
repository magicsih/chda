사람 검토 대기. 합성 데이터를 사용한 설계 시안입니다. 구현 완료·실제 앱 검수·배포 증거가 아닙니다. 본문 정본은 design.md이며, 승인 대상은 이 두 파일을 포함하는 정확한 커밋입니다.

#149 · #150 · #151 · #152 · #154 · #155 · #161 · #164

01 · 지금 하는 작업을 먼저

세 개의 동등한 섹션, 안정적인 선택 위치, 부모에 연결된 하위 작업, 기록을 남기는 알림.

탐색 규칙. 이미 보이는 행은 강조만 바꿉니다. 위·아래에 숨은 행은 해당 가장자리까지만 이동합니다. 배경 작업은 스크롤·접기·focus를 변경하지 않습니다.

실행 중 기록. 알림을 열면 기존 항목만 읽음 처리합니다. 이후 새 항목은 다시 unread가 됩니다. 정상 재시작은 기록을 비웁니다.
