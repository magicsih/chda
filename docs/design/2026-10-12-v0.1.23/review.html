2. 프로그램 종료와 창 닫기를 분리

PROCESS EXIT

끝난 출력은 그대로 남습니다

Tests passed.
Agent finished.

Exited — code 0

pane·tab·window와 scrollback을 유지합니다. 살아 있는 shell이면 같은 shell로 돌아옵니다. 새 shell·agent를 자동 실행하지 않습니다.

EXPLICIT CLOSE

자식 작업이 남았다면 확인합니다

부모가 Idle이어도 Working·Waiting·Unknown 자식이 있으면 중지 확인을 표시합니다. 처음 선택은 Cancel입니다.

Enter는 처음에 취소합니다. Tab으로 중지 버튼을 선택한 뒤 Enter/Space로 확정합니다.

3. 메뉴를 닫으면 입력은 원래 위치로

terminal 입력 중→Usage / context menu→Escape · × · 비이동 action→같은 pane의 입력

새 tab/pane을 여는 action은 목적지에 focus를 둡니다. 메뉴가 열려 있는 동안 tooltip은 표시하지 않습니다.

raw OS 번호·파일 내용 없이 설명합니다. 모든 항목 검증 후에만 복사합니다.

4. 선택한 부분의 들여쓰기만 복원

  }

UNIQUE SOURCE MATCH

선택 밖 내용은 붙이지 않습니다

fn main() {
    println!("hello");
}

- Parent item
  - Nested item

확인된 대화·표시 형식의 유일한 원문 대응에서만 보정합니다. 모호하거나 알 수 없는 형식은 원래 선택을 유지합니다.

ordinary Copy는 유지합니다. clipboard는 미리보기의 Copy를 확정할 때만 바뀌며 메시지를 전송하지 않습니다.

5. 공백을 포함한 실제 전체 경로

/tmp/example/Notes Folder/file.txt:3:2

짧은 /tmp/example/Notes가 존재해도 위 전체 파일이 우선합니다. hover·click·path menu는 같은 target을 사용합니다.

기존 명시적 링크 우선→같은 logical line 후보→최대 16회 확인→가장 긴 existing target

hard newline·인접 경로는 연결하지 않습니다. 탐색 한도를 넘으면 잘린 prefix를 선택하지 않습니다.
